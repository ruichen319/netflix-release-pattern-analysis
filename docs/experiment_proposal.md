# Proposed randomized promotion test

The public chart analysis generates a timing hypothesis. It does not contain campaign exposure, user-level behavior, costs or experiment results.

| Decision | Proposal |
|---|---|
| Candidate periods | All-at-once: Weeks −1 to +5; split release: Weeks −1 to +10 |
| Comparison | Added older-season promotion vs. business as usual, within each format |
| Assignment | Randomize eligible users; define eligibility with internal product data |
| Primary outcome | Weekly TV viewing hours per randomized user, including assigned users with zero viewing |
| Supporting check | Total viewing hours per randomized user, to detect substitution across content |
| Season selection | Keep previous-versus-earlier targeting exploratory |
| Series applicability | Review the series' timing pattern before choosing a launch-centered test; Ms. Rachel illustrates an exception |
| Scale-up rule | Meet a pre-agreed lift threshold without unacceptable declines in agreed guardrail metrics |

Before launch, define treatment exposure, eligible users, common follow-up period, sample size, test duration, success threshold and guardrails using internal baselines and business priorities. The public dataset cannot supply these parameters, so no numeric power or ROI estimate is invented.

Compare outcomes by randomized assignment rather than only among users who clicked or watched the promoted title. This estimates the incremental impact of offering the added promotion within the chosen period. It does not establish that this is the optimal period or identify a causal advantage of one release format.

No experiment was conducted as part of this portfolio project.
